# Common Failure Patterns and Fixes
- "No such collection": Fix the collection ID (e.g., LANDSAT/LC08/C02/T1_L2 not LANDSAT/LC8/C02/T1_L2).
- "Property 'X' not found": Fix the band name (e.g., SR_B5 not B5).
- "0 images found": Widen the date range or switch to a fallback collection.
- "Computation timed out": Increase scale (e.g., 1000 → 3000) or reduce maxPixels.
- "list index out of range" after collection check: The collection was empty — output C1.
- NaN / None result: Add null checks before comparisons — output C3.
- Syntax/indentation error: Fix the specific line.

# Core Requirements
1. Concise Evidence: Max 20 lines of printed output.
2. The Options: Your code must determine the answer and output one of the following tags as the final line:
   - A: Yes
   - B: No
   - C1: Empty Collection
   - C2: No Valid Pixels
   - C3: Calculation Failure
   - D: Code/API error

3. GEE Best Practices:
   - Use named arguments for `reduceRegion`: `reduceRegion(reducer=ee.Reducer.sum(), geometry=geom, scale=1000, maxPixels=1e9,)` use a scale of at least 1000 or 3000 to avoid timeout
   - Define geometries explicitly (Point/Polygon). Do not use `FAO/GAUL`.
   - Use `.And()` / `.Or()` for filters, not native Python `.and()` / `.or()`
