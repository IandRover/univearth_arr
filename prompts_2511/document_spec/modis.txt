If you use MODIS, consider the following:
1. Use only well-supported MODIS collections relevant to the question. Recommended subset:
    Surface Reflectance:
    - MODIS/061/MOD09GA     # Daily surface reflectance (1km)
        Key bands: sur_refl_b01 (RED), sur_refl_b02 (NIR), sur_refl_b04 (GREEN), sur_refl_b03 (BLUE)
    - MODIS/061/MOD09GQ     # Daily surface reflectance (250m)
        Key bands: sur_refl_b01 (RED), sur_refl_b02 (NIR)

    Vegetation Indices:
    - MODIS/061/MOD13Q1      # NDVI/EVI, 16-day composite
        Key bands:  NDVI, EVI

    Land Surface Temperature:
    - MODIS/061/MOD11A1      # Daily LST
        Key band: LST_Day_1km

    Fire / Thermal Anomalies:
    - MODIS/061/MOD14A1      # Daily active fire
        Key band: FireMask

    Snow/Ice:
    - MODIS/061/MYD10A1      # Daily snow cover
        Key band: NDSI_Snow_Cover

    Aerosol:
    - MODIS/061/MCD19A2_GRANULES    # Daily MAIAC AOD
        Key bands: Optical_Depth_047,  Optical_Depth_055

    Land Cover:
    - MODIS/061/MCD12Q1     # Annual land cover
        Key band: LC_Type1
